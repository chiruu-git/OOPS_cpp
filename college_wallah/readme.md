USER DEFINED DATATYPES
User-Defined Data Types (UDTs) are data types that you, as the 
programmer, create yourself. While C++ comes with built-in or 
"primitive" types (like int, float, and char) that hold a 
single value, user-defined types allow you to group multiple 
values, often of varying types, into a single, cohesive unit.
